    C++23 Lesson 1: Development environment

    Why choose a tutorial on C++23? Because I started as a software engineer and I have always loved this language. The first time I flew to Barcelona with a group of friends was in the early 2000s. During the flight, I took my backpack and pulled out my copy of "Thinking in C++" to learn it.

    Even though C++ is an old language, it is still used everywhere. Many AI libraries are written in Python but implemented in C++. Video games are written in C++, and blockchain algorithms are often written in C++. So this language is still widely used in many areas.

    The first thing to do when you pick a programming language is to set up your development environment. We will install an editor to work with the language, and for convenience I chose Visual Studio Code. Now that we have an editor to write instructions, we need another tool that can understand them. This is the compiler. Its job is to translate our code into a language that the computer's processor can execute. The operation happens by providing the sources (files with .cpp and .h extensions) to the pre-processing phase, where the code is merged into a single expanded source file. The compiler then translates it into a sequence of object files. Object files contain all the information the linker needs to transform the intermediate files into an executable that a user can run.

    Let's recap how to set up our development environment:

    1. Install Visual Studio Code
    2. Install the C/C++ extension from the VS Code marketplace
    3. Install the Code Runner extension from the VS Code marketplace
    4. Install MSYS2 a. Start MSYS2 and run the following command using the default options 
      pacman -S --needed base-devel mingw-w64-ucrt-x86_64-toolchain
      b. Add the folder C:\msys64\ucrt64\bin to the PATH environment variable

    At this point our development environment is ready and we can create our first project. Create a folder on your Desktop with a file named main.cpp and add the following code:

    Line 1 is a directive used by the pre-processor and tells the compiler to take the code of iostream.h and paste it where the directive is. Line 3 is the entry point for any executable produced by C++. This means the processor looks for the point called main and starts executing the instructions line by line. Line 4 prints "Hello World" to the console and adds a new line at the end. Finally, the entry point must tell the operating system that execution is complete, which it does by returning a code shown on line 6.
